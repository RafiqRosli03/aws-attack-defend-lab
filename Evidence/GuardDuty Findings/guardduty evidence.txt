DEFENSE-IN-DEPTH INSIGHT
---------------------------------------------------------------------
- WAF sees only HTTP (application layer): caught SQLi + XSS, but is BLIND to
  port scans and host malware.
- GuardDuty sees network + DNS + host behavior: caught the port scan (recon)
  and the malicious files on the instance.
- Each layer covers a different blind spot. No single tool catches everything.

NOTE ON REGIONAL SERVICE AVAILABILITY (important lesson)
---------------------------------------------------------------------
In ap-southeast-5 (Malaysia), the following are NOT available:
  - Amazon Macie      (sensitive data discovery)  -> "Region Unsupported"
  - Amazon Detective  (investigation graphs)      -> not offered
Architectural takeaway: always verify each service's regional availability.
Newer regions may lack services present in mature regions (e.g. Singapore
ap-southeast-1 supports Macie + Detective). If required, deploy in a
supported region.
